# 本项目的模拟评估约束

- 用户明确要求：任何中大规模模拟，均不得对两个不同打法进行同种子对照，包括训练、筛选、回归与最终评估。不同打法使用独立、互不重叠的随机种子，比较分布平均表现，不假设同一种子对不同打法等难。
- 种子用于复现某一局。允许对同一配置、同一版本的失败局开启详细诊断重放；不得以复现为名重建大规模跨打法配对。
- 已完成历史数据可以保留和复用，但不得继续旧的配对调度。训练不反复重测 A/B 基线或样本已经充分的冠军；新增预算优先给新候选和样本不足的有希望候选。
- 正常大规模运行关闭详细诊断和操作审计，只保存参数、版本、种子及必要的终局/关次摘要。需要定位某次失败时，再对该局开启 trace 复跑。
- 当前有效训练入口是 `tools/efficient_train.py`。`anchor_train.py`、`random_train.py` 以及准备阶段脚本含历史配对流程，仅可查阅或复用不涉及采样的辅助函数，不得直接用来启动新的中大规模配对模拟。
- 连续全难度策略测量现使用初始阳光 100000、阳光上限 2147483647，正常产阳光与扣费，统计成功关净消耗；不与旧的初始8000/上限9990结果直接混比。`tools/evaluate_planning_stage.py` 已采用此默认值，历史复现可显式指定旧配置。
- 当前按每项300局推进；用户已要求暂不跑1000局，除非之后重新明确要求，不自行启动1000局比较。更多阳光消耗若能换来明显通关收益可以保留，仍应分析可避免的浪费。
